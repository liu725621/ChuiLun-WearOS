# 垂纶 · ChuiLun v2

为 **三星 Galaxy Watch 7（Wear OS 5 / One UI 6 Watch）** 开发的体感钓鱼 + 生物图鉴收集游戏。

> 机制与画面语言对齐《鱼影》，但**素材、字体、文案、代码全部原创**，未使用其任何资源。

## 二、核心循环

1. **选钓场** — 16 个场景，按生物收集数解锁（0/5/12/20/30/42/55/68/80/92/105/118/132/146/160/175/190）
2. **挥臂抛竿** — 陀螺仪 + 线加速度捕捉力度，落点 3–99 米；抛竿消耗一枚鱼饵。抛竿页就是一块仪表：左侧 0–99M 刻度尺、中间竖表、右下鱼饵
3. **等待咬钩** — 浮标落水到咬钩 3–18 秒，其间有假动作；咬钩瞬间整屏「提竿」三角
4. **遛鱼博弈** — 按住收线、松手放线，张力进红区过久断线；左侧刻度尺变成剩余距离，右侧竖表是张力
5. **结算** — 立绘 + 星级 + 尺寸标尺 + 金币结算 + 保护物种放生提示

## 三、钓鱼指数系统

**分时段鱼口预报表**（「今日鱼情」页）：

```
清晨 05–07   ★★★★☆
白昼 08–16   ★★☆☆☆
黄昏 17–19   ★★★★★
夜晚 20–04   ★★★☆☆
```

分数由 **天气 × 季节 × 月相 × 气压模拟** 加权算出（0–100），并且**真实作用于出鱼权重**。
深水钓场（远洋深水 / 暮光区 / 海沟 / 极地）不看日光，改看**潮汐与月相**。

**单体活跃度与趋势箭头**：图鉴每个已捕获物种显示今日活跃度（★1–5）与 ▲/▼/— 趋势，
并给出推荐钓场与建议抛投距离。趋势由「今天权重 vs 昨天权重」直接计算，不需存快照。

## 四、每日事件系统

| 类型 | 说明 |
|---|---|
| **每日主题事件** | 每天 0 点刷新，30 个事件池轮换。例：冷水上涌（深渊稀有度 +50%）、沙丁风暴、雷雨将至、极光之夜 |
| **限时鱼汛** | 每天 1–2 场，持续 1–3 小时，指定钓场高星鱼权重提升；开启与结束各推一次通知 |
| **节日与节气** | 中国法定节日 + 24 节气，当天有额外稀有度加成 |
| **神秘事件** | 概率受主题事件倍率影响；抛竿前有 22% 概率出现**预兆**提示 |

## 五、安装与真机调参

```bash
# 手表开开发者选项 → ADB 无线调试，记下 IP:端口
adb connect <手表IP>:5555
adb install -r 垂纶-v2-debug.apk
```

或 Android Studio 打开本工程直接 Run。

**所有手感参数集中在 `config/Tuning.kt`**，改完重新编译即可：

| 现象 | 调整 |
|---|---|
| 轻轻一挥就满力 | 调大 `GYRO_FULL_SCALE` / `ACCEL_FULL_SCALE` |
| 甩到手酸才半格 | 调小上面两个值，或进 App 做「校准力度」 |
| 遛鱼太容易 / 太难 | `TENSION_BASE`、`TENSION_PULL`、`REEL_RATE`、`DANGER_TOLERANCE` |
| 等太久 | `WAIT_MAX_MS` |
| 大物太难出 | `RARITY_EXP`、`MULT_FAR` |
| 见不到彩蛋 | `EVENT_CHANCE`（现为 0.07） |

## 七、立绘管线

```
ImageGen 生成 1024×1024（纯品红底）
  → 边框取样 + 高饱和品红识别的连通域抠图
  → 只保留最大连通主体（清掉模型画的零散粒子）
  → 裁包围盒居中 → 降采样到 256px → 24 色量化 → PNG-8 透明底
  → app/src/main/assets/fish/<species_id>.png
```

**未生成的物种会自动回落到程序化像素绘制**（`render/PixelPainter.kt`），界面永不空缺。

## 九、数据说明

161 种生物均带真实资料：学名、体长体重区间、世界纪录体长、栖息水深、分布、习性、食性、冷知识。
其中 20 余种标记为**保护物种**，钓获后显示「已记录并放生」。

104 件「垃圾与旧物」为非生物彩蛋，含灭绝物种（邓氏鱼 / 菊石 / 龙王鲸）、传说生物（锦鲤之王 / 河童）、
现代遗物（河底共享单车 / 落水的手机 / 别人的路亚假饵 / 隔壁钓友的鱼护 / 阿尔戈浮标）等。
