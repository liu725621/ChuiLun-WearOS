安装

  1. 在手表上打开「开发者选项」，启用 通过 WLAN 调试（或 ADB 调试）。
  2. 把 APK 下载到手机或电脑，用 adb install chuilun-v2.3.0-debug.apk 安装；
    也可借助 Wear OS 工具箱 / Bugjaeger 从手机推送。
  3. 首次进入先做一次「校准抛竿力度」，按提示自然挥三次手臂即可。
  4. debug 签名，覆盖安装前若提示签名不一致，请先卸载旧版（存档会清空）。

这一版改了什么

  • 修复真机圆形屏裁切：左侧 0–99M 刻度数字、顶栏两端、左下「抛竿」、右下鱼饵原先被圆弧啃掉。
  • 根因是设计稿按 192dp 排布，真机却是 240dp（480px @ 2.0），坐标随系统密度漂移。现在统一把设计密度按屏幕直径归一化，所有界面在任意圆形屏上保持相同相对位置。
  • 渲染快照测试改为真机尺寸（240dp），并加入圆外像素自动检测，避免再出现「快照没问题、真机被切」。
  • 抛竿 / 提竿 / 遛鱼 / 上鱼界面延续 v2.2.0 的《鱼影》式仪表布局。
